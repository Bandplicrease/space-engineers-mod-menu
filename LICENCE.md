## ✨ Features

### ESP
- Grid Viewer — visualize grid connections and block placement
- Show Hitboxes — display block hitboxes and weld points
- Replay Notes — record and review build sequences
- Playback Speed — adjust editor playback for study (0.1x to 5x)

### Wallhack
- Block Catalog — browse blocks, colors, skins, and effects
- Custom Skin Notes — organize player and grid cosmetics
- Solid Trail Notes — improved visibility for grid trails

### Aimbot
- Build Mode Notes — segment study on any layout
- Gravity Control — manually switch gravity for testing
- Inventory Buffer Notes — chain complex maneuvers in the editor
